# 📚 StudyHub - TYBCA Study Material

StudyHub is a comprehensive web application designed to provide TYBCA students with easy access to notes, assignments, and study resources across multiple subjects. The website organizes study material in a modern, responsive, and user-friendly layout, making it easier for students to download and review resources.

---

## 🔗 Live Demo
[StudyHub Live](https://zackdevd.github.io/StudyMaterial/)

---

## 📝 Features

- **Modern UI**: Clean, responsive design using Bootstrap 5 and CSS variables.
- **Downloadable Resources**: Direct download buttons for PDF study material.
- **Multiple Subjects Covered**:
  - .NET
  - AWD (Advanced Web Development)
  - CC (Computer Concepts)
  - LOS (Linux Operating System)
  - NT (Networking)
  - SEC (Security)
  - WFS (Web Frameworks & Scripting)
- **Scroll to Top Button**: Smooth scroll functionality.
- **Responsive Design**: Fully mobile-friendly and optimized for all screen sizes.
- **SEO Optimized**: Meta tags for search engines and social media sharing.

---

## 🛠️ Technologies Used

- **Frontend**:
  - HTML5
  - CSS3 (with CSS variables and responsive grid)
  - Bootstrap 5
- **Fonts**:
  - Google Fonts (Poppins)
- **Assets**:
  - Study material PDFs stored locally in `Material` folder
- **JavaScript**:
  - Smooth scroll and scroll-to-top functionality
